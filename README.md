# x4pro-emu

A QEMU-based emulator for the Xteink X4 Pro e-reader (ESP32-S3, 800x480 e-paper, GT911 touch), driven
from the shell: boot a firmware image, press buttons, tap the screen, read the console, dump the panel to
PNG, query device state as JSON. Built for developing custom firmware (CrossPoint) and studying the stock app.

Start with [CLAUDE.md](CLAUDE.md) (build, run, CLI, device safety rules), then
[docs/hardware.md](docs/hardware.md), [docs/audit.md](docs/audit.md), and [docs/log.md](docs/log.md).
